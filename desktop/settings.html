Flight data contact

Enter your email or HTTPS project URL to identify this installation to ADSB.lol. It is sent with flight requests when you enable flight traffic.

Leave blank to keep live flights unavailable.

ArcGIS API key

Surface imagery comes from Esri World Imagery. A free ArcGIS Location Platform account includes 2 million tiles a month; paste its API key here so imagery is metered to your own allowance.

Leave blank to use the public endpoint, which is intended for personal use only. Saving reloads the globe.

NASA FIRMS map key

Active fire detections need a free FIRMS map key (firms.modaps.eosdis.nasa.gov/api/map_key). Requests are metered to your own key.

Leave blank to keep the fire layer unavailable.

AISStream API key

Ship positions need a free AISStream key (aisstream.io). While the ship layer is on, one live connection is held from this computer.

Leave blank to keep the ship layer unavailable.
